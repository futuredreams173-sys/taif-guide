# مرشد الطائف — Taif Guide

تطبيق ويب سياحي عربي–إنجليزي لمدينة الطائف: أماكن تاريخية وأثرية وزراعية،
مواسم الورد والمنتجات، مسارات الهايكنج، مع خرائط وصور حقيقية موثقة.

قابل للتثبيت على الجوال (PWA).

## التشغيل محلياً

افتح `index.html` في المتصفح، أو شغّل أي خادم static:

```powershell
python -m http.server 8000
```

## النشر على GitHub Pages

الفرع `main` منشور مباشرة عبر GitHub Pages (Settings → Pages → Deploy from branch).

## الصور

جميع الصور في `images/` فوتوغرافية حقيقية: صور المشروع الخاصة (الورد، سوق عكاظ، جبل قرنيت، نقوش العرفاء)،
وصور Wikimedia Commons المرخصة (CC BY / CC BY-SA) مع سطر التوثيق أسفل كل صورة.
